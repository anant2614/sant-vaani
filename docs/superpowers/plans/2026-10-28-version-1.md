# Sant Vaani Version 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working version of Sant Vaani: the Supabase backend, the Curator Studio that fills it, the nightly jobs, Ask, and the Expo app with its five tabs.

**Architecture:** One npm-workspaces monorepo. `packages/core` holds pure TypeScript shared by every part (theme tokens, sun times, the catalogue format, matching and the crisis screen). Supabase holds the database, sign-in, storage and Deno edge functions. The app never queries content tables: it reads one catalogue file that a nightly job publishes to storage, plus a bundled SQLite Gita.

**Tech Stack:** Expo SDK 58 (React Native 0.88, expo-router), Next.js 16, Supabase (Postgres 17, Auth, Storage, Edge Functions on Deno 2), `@anthropic-ai/sdk` 1.x with Claude Opus 5.5, zod 4, vitest 5, jest-expo, Playwright.

**Spec:** `docs/architecture.md` (exported from the Sant Vaani App Architecture doc).

**Execution:** Native. One agent implements every task in order on branch `v1-foundation`, then one whole-branch review.

## Global Constraints

- Node 22, npm workspaces (`apps/*`, `packages/*`). Every part is TypeScript.
- Supabase region ap-south-1 (Mumbai). Anonymous sign-in on first open; Apple, Google or phone can be linked later.
- Row-level security on every table. A person reads and writes only their own profile, saves, notes, path progress and asks.
- Saints speak, AI only finds: no model output is ever shown to users as teaching text. Summaries are written by curators.
- Every clip comes from an allowlisted official channel, a written permission or a license; the row records which (`rights_basis`).
- YouTube: free tier only, YouTube's own player, never autoplay, stops when the screen closes, player at least 200×200, stored YouTube data refreshed or deleted within 30 days, Terms and Google Privacy Policy linked.
- Answers have 3 to 5 clips by different saints, a tying Gita verse and one small step. An answer stays visible while at least 2 clips remain live.
- Clips on sensitive topics (grief, self-harm, family conflict) need a second reviewer who is not the first.
- Every typed question gets a crisis check before matching. Crisis shows Tele-MANAS (14416 or 1800-891-4416) before any clip, stores no question text, and sends no analytics text.
- Ask uses `claude-opus-5-5` at `effort: "low"` with structured output; model name comes from env `ASK_MODEL` so Haiku 5.5 can be tested. Clip suggestions use the Batch API and read only title, description and chapters.
- Accounts are 18+ at launch (age confirmation in the welcome screen). Account deletion is in Settings.
- Analytics (PostHog) and crash reports (Sentry) are optional by env and never receive question text, notes or names.
- Theme: Ganga Ghat by day and Chandni at night, switched at sunset for the chosen city, or following the phone. Fonts: Marcellus, Mukta, Tiro Devanagari Sanskrit.

## Out of scope for this branch

The website and share pages (Next.js on Vercel), Plus and dakshina through RevenueCat, partner uploads, community questions, recitation audio, and word-by-word, Hindi and English meanings for the Gita. The schema leaves room for each, and they follow as their own pull requests.

## Review Focus

- A question typed in Hinglish or Hindi script with self-harm intent but none of the screen's keywords must still reach the helpline: the model's `crisis` flag is honored even when it also returns matches (Task 5 test `crisis flag wins over a strong match`).
- The Claude API timing out or returning unparseable output must not leave the person without a reply: Ask falls back to lexical matching and nearest topics (Task 5 test `falls back to lexical matching when the model call fails`).
- A curator removing a clip, or a saint being taken down, must never publish an answer with fewer than 2 live clips or one whose clips repeat a saint (Task 3 SQL test `publish_answer rejects repeated saints`; Task 6 test `drops answers with fewer than 2 live clips`).
- A first open with no network must still show Today: the bundled catalogue snapshot and the bundled Gita load without a request (Task 9 test `loads the bundled catalogue when there is no cache`).
- Midnight and sunset edges: the theme must not flicker between schemes at the boundary minute or in cities where the sun does not set on that date (Task 1 tests `switches exactly at sunset`, `polar day stays light`).
